Modpack setup

Build your instance.

A small, configurable setup guide for joining the server with Prism Launcher.

Step 01

Download Prism Launcher

Prism Launcher is an open-source Minecraft launcher that makes managing custom profiles straightforward.

  1. Download the installer for your operating system.
  2. Run the installer and complete the setup wizard.
  3. Launch the application and choose your language and Java version.
Open Prism Launcher
Step 02

Sign in to Minecraft

When Prism Launcher starts for the first time, connect the Microsoft account that owns Minecraft.

  1. Select Sign in with Microsoft and follow the prompts.
Quick note: If sign-in errors, wait a little while and try again.
Step 03

Add to game

  1. Copy the link link.
  2. In Prism Launcher, select Add Instance.
  3. Choose Import, paste the link, and confirm.
  4. If you want, add other mods such as Carpet Mod, MiniHUD, Shaders.
  5. If you want to, change the RAM allocation of the profile.
https://github.com/rumsteak08/Server/releases/download/V3/Durham.S2.mrpack

When the download finishes, double-click the new profile icon to start playing.
