Voice chat

Join voice chat from the web UI

Voice chat uses a web interface. Before you can log in, you must set a voice chat password while you are online on the Minecraft server.

1. Join the Minecraft server

Start Minecraft and connect to the server normally. You must be online for the password command to work.

2. Set your voice chat password

Open the in-game chat and run the command below. Replace PASSWORD with a password you will remember.

/svg pswd PASSWORD
Keep it private: Do not share this password with anyone. It is used to log in to the voice chat web UI.

3. Open the voice chat web UI

Open vc.dont-spam-me.uk in your browser.

4. Log in

  1. Enter your Minecraft username exactly as it appears in game.
  2. Enter the password you set with /svg pswd PASSWORD
  3. Submit the login form.

5. Join a voice channel

After logging in, choose the voice channel you want to join from the web UI. Allow microphone access when your browser asks for permission, then select your microphone and output device.

Having trouble? Check that you are currently online on the server, that your username is spelled correctly, and that your browser has permission to use your microphone.
Player profile

Reset your nickname

Your displayed nickname may need to be reset if it is outdated, misspelled, or does not match what you want other players to see.

1. Be online

Join the Minecraft server before running the command. Server commands only work while you are connected.

2. Run the nickname command

Open the in-game chat and replace NICKNAME with the name you want to use.

/nickname NICKNAME

3. Check the result

Look at the player list or chat to confirm that your new nickname is showing correctly. If it does not update immediately, reconnect to the server and check again.

Tip: Choose a nickname that is easy for other players to recognize and follow the server's community rules.
